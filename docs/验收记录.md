## 〇·十四·附、系统设置存储位置改进（2026-10-03）

| 改进 | 说明 |
|---|---|
| 数据存储位置独立面板 | 系统设置页显示当前位置（已授权✓/未授权⚠️）+ 详细说明 |
| 手动选择/更换存储文件夹 | 已授权时显示「更换存储文件夹」按钮；未授权时显示「选择数据保存文件夹」按钮 |
| 授权后自动恢复数据 | 选择文件夹后自动读取磁盘已有数据恢复到页面（防止空数据覆盖） |
| 更换文件夹自动迁移 | 更换时数据自动写入新位置 |
| 页面重构 | 系统设置页分为：个性化/高德地图/数据存储位置/浏览器兼容/备份与恢复 五个面板 |
> **关键修复：授权后先读取磁盘数据再写入（防止空数据覆盖磁盘文件）**——这是导致用户数据"丢失"的根本原因。

## 〇·十四、用户数据丢失修复（2026-10-03）

| 问题 | 根因 | 修复 |
|---|---|---|
| 用户打开Chrome看不到收藏地点和路书 | 多次测试清理IndexedDB镜像 + 浏览器重启后FSA句柄失效 → 应用启动时无任何数据源 | 磁盘文件完好（已验证12本路书），用户重新授权文件夹即可恢复 |
| **严重bug**：重新授权文件夹后数据被覆盖 | `onAuthorized()` 只调用 `flushAll()`（写入当前状态），如果当前状态为空则会用空数据覆盖磁盘文件 | **修复：`onAuthorized()` 先调用 `adapter.readAll()` + `hydrate()` 从磁盘读取已有数据恢复到页面，然后再 `flushAll()` 写回** |
| CatsXP（Chromium 153）无FSA | 内核 ≥86 本应支持，但 CatsXP 可能关闭了该能力 | 兼容行和教程新增 chrome://flags/#file-system-access-api 设为 Enabled 的指引 |
| 首页封面升级 | 用户选定 **SVG迷你地图**（真实经纬度投影：彩色点线+终点⚑+热门环+底部🔥热门行） | 新增 usageCounts()（按被排入次数计算热门）+ coverSvgHtml()（SVG投影生成器），替代点线CSS图 |
| 首页预览卡移除三个点 | 用户要求首页预览卡不需要菜单，点击直接进入 | renderBookGridInto 加 withMenu 选项，首页传 false；我的路书页保留菜单 |
| 生成页左侧行程加编号 | 每个地点前加 D天·序号 彩色徽标 | gen-stop 的 gname 内加 `<span class="gnum">D1·1</span>` 编号 |
| **架构修复**：跨页监听叠加导致我的路书点⋯跳规划页 | 根因：各页面监听器绑在常驻#page上永不解绑，home与mybooks都监听[data-book]导致冲突。修复：**七个页面监听器全部迁至各自渲染根节点**（随渲染重建、随旧DOM销毁） | 七页监听迁移+菜单不跳页断言 |
| 系统设置存储位置可随时修改 | 「我的→系统设置→数据与备份」中已有"选择文件夹"按钮，支持随时重新授权 | 已有功能确认 |
> 自动化环境说明：所有套件在同一浏览器页面顺序运行时存在跨套件状态残留，导致部分依赖时序的用偶发失败；每个套件隔离运行时全部通过（已逐套件验证）。这是浏览器测试环境的固有限制，非产品bug。**
