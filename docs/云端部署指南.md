# 路书 (LuShu) · 云端与多端部署指南

本系统已全面升级为 **前端 + 后端 (Python) + SQLite 数据库** 现代架构：
- **数据统一存储**：所有路书、收藏地点、分类标签、系统设置均存储在服务端的 `data/lushu.db`（SQLite 数据库）中；
- **全设备实时同步**：电脑、手机、平板、NAS或远程外网访问同一服务器地址，看到的都是同一份数据，修改实时保存，彻底告别单机导入导出迁移；
- **轻量零外部依赖**：服务端基于 Python 3.9+ 原生标准库，无 pip 第三方依赖包，资源占用低（仅需数十兆内存），开箱即用。

## 一、一键打包（Mac 本地）

在项目根目录下，双击运行 **「打包部署.command」**：
- 脚本会自动提取生产所需代码（`server.py`、`index.html`、`css/`、`js/`、`vendor/`、`Dockerfile`、`docker-compose.yml` 等）；
- 自动剔除本地开发日志、系统临时文件、个人敏感配置；
- 在根目录下生成 **`路书-云端部署包.zip`** 以及 `deploy-dist/` 文件夹。

## 二、云服务器部署：Docker Compose（推荐）

适用于任何主流 Linux 云服务器（腾讯云、阿里云、华为云、AWS、轻量应用服务器、各种 VPS 等）。

### 1. 安装 Docker 与 Compose
如果服务器尚未安装 Docker，可执行官方一键脚本：
```bash
curl -fsSL https://get.docker.com | bash
systemctl enable --now docker
```

### 2. 上传部署包
将 `路书-云端部署包.zip` 上传至服务器（例如 `/opt/lushu`）：
```bash
mkdir -p /opt/lushu
cd /opt/lushu
# 解压到当前目录
unzip -q 路书-云端部署包.zip
# 移动解压出来的 deploy-dist 文件到当前根目录（若解压为子目录）
cp -r deploy-dist/* . 2>/dev/null || true
```

### 3. 一键启动
在包含 `docker-compose.yml` 的目录下执行：
```bash
docker compose up -d --build
```

### 4. 验证与访问
- 检查容器状态：
  ```bash
  docker compose ps
  ```
- 浏览器打开：`http://你的云服务器公网IP:8123/`
  *(注意：请确保云服务器控制台的安全组/防火墙已放行 `8123` 端口)*

### 5. 常用运维命令
- **查看运行日志**：`docker compose logs -f`
- **停止服务**：`docker compose down`
- **重启服务**：`docker compose restart`
- **更新版本**：上传新文件后重新执行 `docker compose up -d --build`

## 三、云服务器部署：1Panel / 宝塔面板

### 1. 1Panel 面板部署
1. 登录 1Panel 面板 → 点击左侧菜单 **「容器」** → **「编排」**；
2. 点击 **「创建编排」**：
   - 名称填写：`lushu`
   - 将项目中的 `docker-compose.yml` 内容粘贴进编排模板；
3. 将解压出来的网站文件放到宿主机对应目录下，点击 **「确认」** 启动容器。

### 2. 宝塔面板部署
- **方式 A (推荐 Docker)**：
  进入宝塔「Docker」模块 →「Compose 模板」→ 添加模板粘贴 `docker-compose.yml` 并启动。
- **方式 B (Python 项目管理器)**：
  进入宝塔「网站」→「Python 项目」→ 添加 Python 项目：
  - 项目名称：`lushu`
  - 路径：选择上传后的项目目录
  - Python 版本：选择 Python 3.9+
  - 启动方式：`python3 server.py`
  - 监听端口：`8123`

## 四、云服务器部署：原生 Linux + Systemd 守护进程

若服务器不想安装 Docker，直接使用系统内置 Python 3 即可无缝运行。

### 1. 简易后台运行（nohup）
```bash
cd /opt/lushu
nohup python3 server.py > server.log 2>&1 &
```

### 2. 生产级系统守护进程（Systemd）
创建系统服务文件：
```bash
sudo cat << 'EOF' > /etc/systemd/system/lushu.service
[Unit]
Description=LuShu Travel Planner Web Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/lushu
ExecStart=/usr/bin/python3 /opt/lushu/server.py
Restart=always
RestartSec=5
Environment=HOST=0.0.0.0
Environment=PORT=8123
Environment=DATA_DIR=/opt/lushu/data
Environment=SERVER_NO_OPEN=1

[Install]
WantedBy=multi-user.target
EOF
```

启用并启动：
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now lushu
sudo systemctl status lushu
```

## 五、域名绑定与 HTTPS (Nginx 反代)

若你需要使用自有域名并通过 HTTPS 访问（推荐，可获得更好的定位与浏览器离线体验）：

### 1. Nginx 配置文件
参考项目中已准备的 `deploy/nginx.conf`：
```nginx
server {
    listen 80;
    server_name lushu.yourdomain.com; # 换成你的域名

    client_max_body_size 50M;

    location / {
        proxy_pass http://127.0.0.1:8123;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 2. 一键申请 Let's Encrypt SSL 免费证书
```bash
sudo certbot --nginx -d lushu.yourdomain.com
```
Certbot 会自动配置 HTTPS 443 端口与证书续期。

## 六、数据迁移与备份

1. **自动迁移本地已有数据**：
   - 首次启动时，如果服务端检测到数据库为空，会自动检测并导入 `路书数据/` 目录下的 JSON 历史数据。
2. **直接迁移本地 SQLite 数据库**：
   - 本地所有数据存放在 `data/lushu.db`；
   - 部署到云端时，可直接将本地的 `data/lushu.db` 拷贝到服务器的 `./data/lushu.db`，所有行程、地点收藏即刻完整还原！
3. **前端一键备份与恢复**：
   - 访问「系统设置」页，点击「⬇️ 导出全部数据」即可随时下载全量 JSON 备份；
   - 在任何新环境点击「⬆️ 导入备份」，即可一键将数据导入数据库并实时生效。
