# 路书应用 · 使用说明

本应用已全面升级为：**前端 + Python 后端 + SQLite 数据库** 现代架构。

## 快速开始

1. **双击项目文件夹里的「启动路书.command」**——服务会在后台启动并自动打开浏览器进入应用。
   - 启动后**不需要保持任何终端窗口**，服务在后台常驻；
   - 如果已在运行，再次双击只会重新打开页面，不会重复启动；
   - 若 macOS 弹出安全确认框，点「打开」即可；若被拦截，请在文件上**右键 → 打开方式 → 终端**。
2. 首次打开两步引导：
   - **① 填写高德Key**：在高德开放平台（lbs.amap.com）申请的「Web端(JS API)」Key 和安全密钥，选填，稍后可在「系统设置」里填；
   - **② 开始规划行程**：数据已自动持久化保存在服务器端的 SQLite 数据库（`data/lushu.db`）中，**无需授权本地文件夹，无需任何手动保存操作**。
3. 以后每次使用：双击「启动路书.command」，打开的就是上次的样子。
4. **想停止服务**：双击「退出路书.command」。

> 想放到云服务器或NAS上外网访问？双击「打包部署.command」生成部署包，详见 [云端部署指南](云端部署指南.md)。

## 六个模块功能

| 模块 | 用途 |
|---|---|
| **首页** | 所有路书的卡片墙（按最近修改排序，带点线图迷你地图封面）。点卡片继续编辑；支持新建路书、直接进入行程 |
| **地图选点** | 输入至少3个字搜地点（默认先定位到你所在位置）→ 点候选看位置 → 「＋加入信息库」时选大类、打标签、写备注。已在库里的会提示，不会重复入库 |
| **收藏地点** | 收集地点的总仓库（所有路书共用）。左侧大类可增删改名、拖动排序；标签可多选筛选；条目可编辑/看地图/删除（删除会提示它被哪些行程使用并级联移除） |
| **规划路线** | 三栏布局：左侧按天排行程（点「＋添加一天」自动延续日期；从右上拖地点进来，或点 ⊕ 追加到选中的天；≡ 手柄拖动排序，可跨天）；每天可设「今晚住宿」自动作为明天出发点；⚡一键就近优化当天顺序；右下地图铺设位置 |
| **生成路线** | 一键生成全程预览（左侧行程单/右侧地图）：高德真实驾车路线按天分色（🚩出发锚 🏨住宿 🏁目的地），每段距离用时，每天标题有全程汇总与宿点，起终点显示天气预报，可选高速优先/不走高速。支持手机端调起高德导航 |
| **我的路书** | 完整路书列表，支持重命名、单份导出、删除路书等操作 |
| **系统设置** | 应用名称个性化、高德Key与天气Key维护、SQLite 数据库状态展示、全量数据一键导出与导入备份 |

## 多设备与手机使用

在同一局域网（如家里或办公室 Wi-Fi）下：
1. 启动服务后，查看控制台打印的局域网地址（如 `http://192.168.1.199:8123/`）；
2. 手机或平板的自带浏览器直接打开该地址即可使用；
3. **数据多端实时共享**：手机上添加地点或修改路书，电脑端刷新即刻同步（因为数据直接保存在服务端的 SQLite 数据库中）；
4. 手机端操作小提示：拖拽排序时**长按约 0.2 秒**后再拖动。

## 数据存储与备份

- **SQLite 单文件数据库**：所有数据自动保存在 `data/lushu.db` 中。
- **备份与迁移**：
  - 可以随时直接复制 `data/lushu.db` 文件进行物理备份；
  - 也可以在「系统设置」页点击「⬇️ 导出全部数据」下载 `.json` 备份文件；
  - 在新电脑或云端服务器上点击「⬆️ 导入备份」，即可一键恢复全量数据。

## 常见问题

- **双击启动没反应**：右键点击「启动路书.command」选择「打开方式」→「终端」；或者查看 `server.log` 排查启动日志。
- **地图空白 / 无法搜索**：在「系统设置」中检查高德 Key 和安全密钥是否已填正确，且为「Web端 (JS API)」类型。
- **如何停止后台服务**：双击「退出路书.command」即可一键安全停止。
