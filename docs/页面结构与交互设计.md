# 路书应用 · 页面结构与交互设计 v1.0（已确认）

> 2026-09-30 确认，作为第一版 UI 与交互实现依据；需求范围与决策以 [PRD.md](../PRD.md) 为准。

---

## 1. 全局框架（所有页面共用）

```
┌────────────────────────────────────────────────────────────┐
│ 🗺 路书   首页 | 地图选点 | 信息库 | 路书规划 | 生成路书    ⚙  │
│                            当前路书: 成都三日游 ▾   ●已保存 14:32 │
└────────────────────────────────────────────────────────────┘
```

- **五个Tab = 五个页面**，点击即时切换，切换不丢失任何已填内容。
- **当前路书芯片**：信息库 / 规划 / 生成页顶部显示"正在编辑哪份路书"，点它可快速切换到别的路书（等同回首页选择）。
- **⚙ 设置弹窗**：填高德Key和安全密钥、数据文件夹授权状态、手动导出/导入全部数据备份。
- **● 自动保存指示**：任何改动约1秒内自动写入项目文件夹，依次显示"保存中… → 已保存 14:32"；写失败变红色"未保存"，点击可重试。
- **首次使用引导**（依次三步小弹窗）：① 授权数据文件夹 → ② 填高德Key → ③ 新建第一份路书。三步都可跳过稍后补。

**通用交互规范**：
- 所有删除操作二次确认；确认弹窗写清楚影响范围。
- 输入类内容"即改即存"，全程没有"保存"按钮。
- 操作反馈用轻提示（右上角浮出，2秒消失）：成功绿色 / 失败红色。
- 每个列表都有空状态文案 + 引导按钮（例如信息库为空时提示"去地图选点收集第一个地点"）。

## 3. 地图选点

```
┌──────────────┬─────────────────────────────────┐
│ 搜索范围: 全国▾ │                                 │
│ ┌──────────┐ │                                 │
│ │🔍 输入3字以上│ │          高 德 地 图              │
│ └──────────┘ │                                 │
│ 候选列表：     │        （选中点落标记高亮）          │
│  ▸ 小名堂冒烤鸭 │                                 │
│    青羊区…    │      ┌────────────────┐         │
│  ▸ 小名堂(分店) │      │ 小名堂冒烤鸭      │         │
│  ▸ …         │      │ 成都市青羊区…     │         │
│              │      │ [ ＋加入信息库 ]   │         │
│ 本次已入库(3)  │      └────────────────┘         │
└──────────────┴─────────────────────────────────┘
```

**交互流**：
1. 输入 ≥3 字自动出候选（名称+地址），键盘上下键可选，回车等同点击。
2. 点候选 → 地图平滑飞到该点、落标记，右下角浮出详情卡（名称、地址、电话、类别）。
3. 点 **[＋加入信息库]** → 弹"归类小弹窗"：
   - 一级大类：下拉选择（选项=信息库现有大类，底部有"＋新建大类"）
   - 二级标签：多选（可现选现建）
   - 备注：选填（如"人均80，需排号"）
   - 确认 → 入库成功轻提示，详情卡关闭，可继续搜下一个。
4. 若该地点已在信息库：详情卡显示"已在信息库"，按钮变为 [查看]（跳信息库并高亮该条目），避免重复入库。
5. 右下角"本次已入库"小列表：连续收集时看得到刚才加了什么，点击可撤销刚才那次入库。
6. 搜索范围默认全国，可输入城市名缩小范围（提高候选准确度）。

## 5. 路书规划（核心页，三栏）

```
┌───────────────┬──────────────────────┬────────────┐
│ ① 行程区（左）   │ ② 信息库调用（右上）     │ ③ 地图（右下）│
│               │                      │            │
│ 名称:成都三日游✎ │ 〔美食〕〔酒店〕〔游玩〕…  │            │
│ 🚩起点:成都 ✎   │ 🔍 标签:[亲子×]        │   高德地图   │
│ ┌───────────┐ │ ┌──────────────────┐ │            │
│ │ D1 · 10月1日▾│ │ │ 小名堂冒烤鸭    ⊕ dragging│ │            │
│ │ ①宽窄巷子  ≡✕│ │ │ 宽窄巷子       ⊕ │ │  点条目→    │
│ │ ②小名堂    ≡✕│ │ │ 亚朵酒店       ⊕ │ │  落标记弹窗  │
│ │ ③锦里     ≡✕│ │ └──────────────────┘ │            │
│ │ 🏨今晚:未设置 ⋯│ │  条目可拖拽到左栏      │  [显示当天   │
│ │ [⚡优化顺序]   │ │  ⊕=追加到当前激活的天  │   连线 开关] │
│ └───────────┘ │                      │            │
│ [ ＋ 添加 D2 ]  │                      │            │
└───────────────┴──────────────────────┴────────────┘
```

### ① 左栏 · 行程区（约40%宽）

- **路书头**：名称、整趟起点、目的地，即点即改。
- **[＋添加一天]**：生成新天卡片 D2、D3……（天数不限），每天手动选日期。
- **天卡片**：
  - 头部：`D1 · 日期▾`；右上 ✕ 删除该天（二次确认，写明将移除该天全部条目）。
  - **条目行**：序号、名称、大类小图标；`≡` 拖拽手柄（同天内上下移动、**也可跨天拖动**）；`✕` 从行程移除（只移出行程，不删信息库）；**点击条目 → 右下地图定位**。
  - **🚩 行程起点**：仅 D1 顶部显示，取自路书"整趟起点"，可就地改。
  - **🏨 今晚住宿**：点"设置"→ 弹选择器（默认筛"酒店"大类、可搜索全部库条目，也能搜新的）→ 选中后固定为**当天最后一个点**；下一天的出发锚点自动继承它（天卡片顶部显示"从：亚朵酒店出发"）。不设也行：当天就以最后一个条目收尾。
  - **[⚡优化顺序]**：固定"出发锚点 + 今晚住宿"两端，中间地点按直线距离就近重排（最近邻 + 局部优化），目标是当天不走回头路、不绕冤枉路；完成后轻提示"已优化，可继续手动微调"。
- 拖拽过程中，左栏显示**插入位置指示线**，松手自动吸附到该位置。
- 点某天卡片 → 该天高亮为"当前激活的天"（右上栏 ⊕ 的目标）。

### ② 右上 · 信息库调用区

- 一级大类按钮组（同信息库的大类）＋ 标签筛选 ＋ 搜索框。
- 条目为紧凑行：**拖拽**到左栏任意位置；**⊕** 一键追加到"当前激活的天"末尾（未激活任何天时 ⊕ 置灰并提示）；**点击** → 右下地图定位。
- 大类切换即时刷新列表。

### ③ 右下 · 地图预览

- 点击任意条目（左栏或右上栏）→ 落标记 + 名称浮窗；多个标记自动缩放视野。
- **[显示当天连线] 开关**：把当前激活天按顺序画驾车细线，直观看出顺序顺不顺；切换天时跟随。
- 地图可自由缩放拖动，不影响其他区域。

## 6. 生成路书

```
┌────────────────────────────────────────────────┐
│ 成都三日游 · 全程预览               [ 去调整行程 ]  │
│ ┌────────────────────────────────────────────┐ │
│ │           高 德 地 图（全程）                  │ │
│ │   D1红线 · D2蓝线 · D3绿线；                   │ │
│ │   🚩起点 🏨住宿 🏁终点 图标区分                  │ │
│ └────────────────────────────────────────────┘ │
│ ▼ D1 · 10月1日 · 宿：亚朵酒店                     │
│    成都 → 宽窄巷子 → 小名堂冒烤鸭 → 锦里 → 亚朵酒店  │
│ ▼ D2 · 10月2日 · 宿：…                           │
│ ────────────────────────────────────────────  │
│ （第二版预留：每天导航二维码）                      │
└────────────────────────────────────────────────┘
```

- **全程地图**：按天分段画**高德真实驾车路线**，各天不同颜色，起点/住宿/终点用不同图标；点标记显示名称。
- **行程单**：按天折叠列表（只读）：天、日期、当晚住宿、按顺序的地点链。
- 从首页/规划页进入时自动带当前路书；若没有，提示"先去首页选择一份路书"。
- [去调整行程] → 回规划页。本页只读，修改一律回规划页做。
- 二维码功能第二版再加（位置已预留），到时按"每天拆段、一段一个码"实现。

## 7. 数据落盘结构（自动保存到项目文件夹）

```
路书web制作/
├─ index.html 等            ← 应用本体（静态文件）
├─ 启动路书.command / .bat   ← 双击启动脚本
└─ 路书数据/                 ← 授权后浏览器直接读写这里
   ├─ 设置.json             ← 高德Key、安全密钥、界面偏好
   ├─ 信息库.json           ← 大类、标签、全部条目
   └─ 路书/
      ├─ 20261001_成都三日游.json
      └─ …
```

- 任何改动防抖约1秒后自动写入对应文件（原子替换写法，防写坏）；文件按日期+名称命名，你可以直接拷走当备份。
- 浏览器内 IndexedDB 同步留一份镜像：文件夹未授权、写盘失败时兜底，恢复授权后自动写回。
- ⚙ 设置里可手动"导出全部数据 / 导入备份"，防清浏览器缓存等意外。
- 双击启动脚本只起一个纯静态本地页面服务（无任何后端逻辑），然后自动打开 Chrome/Edge。

## 8. 我按默认处理的点（请拍板，有不同意见直接说）

1. **删除信息库条目**：引用它的行程一并移除（删除前弹窗写明影响）。
2. **优化顺序**用直线距离估算（瞬间完成、不耗高德配额）；生成预览的画线用真实驾车路线。优化结果直接应用，不做"前后对比预览"，不满意手动拖回即可。
3. **行程条目不排具体时间**，只有先后顺序（需要精确到几点几分再说）。
4. **允许跨天拖拽**：把某天的条目拖到另一天。
5. **没设当晚住宿的天**：出发锚=前一天住宿（或整趟起点），终点=当天最后一个条目，照样能优化顺序。
6. **日期全部手动选**，不自动按出发日推算。
7. **删除路书**只删路书文件，信息库条目保留。
